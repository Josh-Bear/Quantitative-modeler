## 1. ภาพรวมโปรเจกต์

โปรเจกต์นี้มีเป้าหมายเพื่อสร้าง **Investor's Views** อัตโนมัติด้วย Machine Learning แล้วนำไปใช้ใน **Black-Litterman Model (BLM)** เพื่อ rebalance portfolio จาก market cap weight ไปสู่ optimal weight

### Pipeline หลัก

```
ข้อมูลราคาหุ้น (OHLCV)
        ↓
คำนวณ Technical Indicators (8 ตัว)
        ↓
LSTM 4 Layers → คาดการณ์ indicator ล่วงหน้า 5 วัน
        ↓
SVR → คาดการณ์ราคาปิดล่วงหน้า 5 วัน
        ↓
คำนวณ Expected Return (Investor's View = Q)
        ↓
Black-Litterman Formula → E[R]
        ↓
Mean-Variance Optimization → Optimal Weight (w*)
        ↓
Rebalance: Market Weight → Optimal Weight
```

## 3. Technical Indicators ที่เลือกใช้

### 3.1 เหตุผลที่ปรับจากชุดเดิม

ชุดเดิม (SMA, EMA, MACD) มี **correlation สูงมาก** เพราะทั้งสามตัวคำนวณจากราคาปิดเหมือนกันและให้ signal ในทิศทางเดียวกัน LSTM จึงเรียนรู้ข้อมูลซ้ำซ้อนโดยไม่ได้ประโยชน์เพิ่ม

### 3.2 ชุด Indicators ใหม่ (8 ค่า / timestep)

| ค่า | สาย | คำนวณจาก | บอกอะไร |
|-----|-----|----------|---------|
| MACD | Trend | EMA(12) - EMA(26) | ทิศทาง + momentum ของ trend |
| RSI | Momentum | avg gain / avg loss | overbought / oversold (0–100) |
| squeeze_on | Volatility | BB อยู่ใน KC? | ตลาดกำลัง compress (0/1) |
| BB_width | Volatility | BB_upper - BB_lower | ความกว้าง SD-based band |
| KC_width | Trend + Volatility | KC_upper - KC_lower | ความกว้าง ATR-based band |
| sq_momentum | Momentum | LinearReg(delta, 12) | ทิศทางพลังงานระหว่าง squeeze |
| OBV | **Volume** (ใหม่) | สะสม volume ตาม direction | volume flow — ขาดในงานเดิม |
| Hilbert | Cycle | HT_DCPERIOD | รอบของราคา (สั้น/ยาว) |

### 3.3 BB/KC Squeeze — จุดเด่นของชุดนี้

แทนที่จะส่ง 6 เส้นแยก (BB upper/mid/lower และ KC upper/mid/lower) ซึ่งมี overlap สูง โปรเจกต์นี้ใช้ **Squeeze features** แทน

```
Squeeze ON  = BB แคบจนอยู่ใน KC ทั้งสองข้าง
            = ตลาดกำลังกักเก็บพลังงาน รอระเบิด

Squeeze OFF = BB กว้างกว่า KC
            = พลังงานถูกปล่อยออกมาแล้ว

sq_momentum = ทิศทางที่พลังงานจะระเบิดออกไป
```

LSTM ได้ประโยชน์จากการเห็น pattern ของ squeeze เช่น duration ของ squeeze, OBV ระหว่าง squeeze, และ RSI ระหว่าง squeeze เพื่อ predict ทิศทางและความรุนแรงของการระเบิด

## 4. Architecture ของโมเดล

### 4.1 LSTM — คาดการณ์ Indicator

```
Input: (samples, 30, 8)
  30 = จำนวน timestep (วันย้อนหลัง)
   8 = จำนวน features

LSTM Layer 1 (hidden=60) + Dropout 30%
        ↓  pattern รายวัน
LSTM Layer 2 (hidden=60) + Dropout 30%
        ↓  pattern รายสัปดาห์
LSTM Layer 3 (hidden=60) + Dropout 30%
        ↓  pattern รายเดือน
LSTM Layer 4 (hidden=60)
        ↓  สรุป pattern ทั้งหมด
Dense (60 → 1)
        ↓
ค่าคาดการณ์ indicator 1 ตัว (ล่วงหน้า 5 วัน)
```

Train แยก 8 โมเดล สำหรับ indicator แต่ละตัว

**Hyperparameters (จาก Grid Search):**

| Parameter | Value |
|-----------|-------|
| Learning rate | 5×10⁻³ |
| Optimizer | Adam |
| Batch size | 256 |
| Epochs | 400 |
| Dropout | 30% |
| Time window | 30 วัน |

### 4.2 SVR — คาดการณ์ราคาปิด

รับ indicator ที่คาดการณ์ทั้ง 8 ตัว แล้ว predict ราคาปิดล่วงหน้า 5 วัน

**Hyperparameters (จาก Grid Search):**

| Parameter | Value |
|-----------|-------|
| Kernel | RBF |
| Epsilon (ε) | 0.01 |
| C | 5 |

## 6. Black-Litterman Model

### 6.1 ภาพรวม BLM

BLM รวม 2 แหล่งข้อมูลเข้าด้วยกัน

```
Prior (Market Equilibrium)     +     Investor's Views (โมเดล ML)
π = δ × Σ × w_market                Q = expected return จาก SVR
        ↓                                    ↓
        └──────────── BL Formula ────────────┘
                           ↓
                    Posterior E[R]
                           ↓
                    Optimal Weight w*
```

### 6.2 ตัวแปรใน BLM

| สัญลักษณ์ | ความหมาย | มาจากไหน |
|----------|---------|---------|
| π | Implied equilibrium return | คำนวณจาก market cap weight |
| Σ | Covariance matrix | ข้อมูลราคาย้อนหลัง |
| w_market | Market cap weight | ข้อมูล market cap |
| τ | Scaling factor | ตั้งค่า ~0.05 |
| P | Pick matrix | กำหนดว่า view เกี่ยวกับหุ้นตัวไหน |
| Q | View return vector | **ได้จาก LSTM + SVR** |
| Ω | View uncertainty matrix | ได้จาก MSE ของโมเดล |
| δ | Risk aversion coefficient | ตั้งค่า ~2.5 |

### 6.3 สูตร BLM

**Step 1: Implied Return (Prior)**
```
π = δ × Σ × w_market
```

**Step 2: Posterior Expected Return**
```
E[R] = [(τΣ)⁻¹ + PᵀΩ⁻¹P]⁻¹ × [(τΣ)⁻¹π + PᵀΩ⁻¹Q]
```

**Step 3: Optimal Weight**
```
w* = (δΣ)⁻¹ × E[R]
```

### 6.4 บทบาทของ MSE ใน BLM

MSE ของโมเดลถูกนำไปใช้กำหนด Ω (uncertainty ของ view)

```
MSE ต่ำ  →  Ω เล็ก  →  BLM เชื่อ view มาก  →  w* ต่างจาก market มาก
MSE สูง  →  Ω ใหญ่  →  BLM เชื่อ prior มาก →  w* ใกล้ market weight
```

## 7. สิ่งที่ต้องทำต่อ

### Phase 1 — Data Pipeline
- [ ] ดึงข้อมูลด้วย `yfinance`
- [ ] คำนวณ indicator 8 ตัวด้วย `pandas-ta` และ `TA-Lib`
- [ ] คำนวณ Squeeze features (squeeze_on, BB_width, KC_width, sq_momentum)
- [ ] Normalize ด้วย MinMaxScaler
- [ ] สร้าง time windows (30 วัน)
- [ ] แบ่ง Train/Val/Test

### Phase 2 — Model Training
- [ ] Train LSTM 8 โมเดล (indicator ละ 1 โมเดล)
- [ ] Grid Search หา hyperparameters ที่ดีที่สุด
- [ ] Train SVR รับ indicator ที่คาดการณ์ → predict ราคาปิด
- [ ] ประเมิน MSE บน validation set

### Phase 3 — Black-Litterman
- [ ] คำนวณ market cap weight (w_market)
- [ ] คำนวณ Covariance matrix (Σ)
- [ ] กำหนด P matrix (Pick matrix)
- [ ] รัน BL formula → E[R]
- [ ] Optimize → w* (Optimal weight)

### Phase 4 — Evaluation
- [ ] เปรียบ w* กับ w_market
- [ ] คำนวณ portfolio return, Sharpe ratio, Max drawdown
- [ ] เปรียบกับ benchmark (S&P500)
- [ ] Test บนข้อมูลปี 2025
